# 灰烬誓约 · ASHEN OATH — 游戏策划与开发路线

更新：2026-09-11。此文已恢复，并按最新要求修订。项目名称为「灰烬誓约」，项目目录为 `ash-oath/`。今晚可玩只是开发里程碑，不是项目名称，也不降低长期美术目标。

## 已确定的方向

- 独立 Godot 桌面游戏；新文件夹，不改写既有游戏。
- 真实 3D 模型和场景，固定斜俯视的 2.5D 观感。
- 只开发野蛮人。技能按《暗黑破坏神 IV》当前正式版本尽量还原机制与数值。
- 鼠标点击地面移动、点击 NPC 交谈、点击敌人攻击；不支持 WASD 移动。
- 剧情采用《暗黑破坏神 II》的主线与人物关系；第一幕从罗格营地、阿卡拉与邪恶洞窟委托开始。对话自行撰写来承接原剧情，不使用原游戏音频、贴图或模型。
- 当前已实现：第一场景、鼠标交互、六个开局可用基础技能、扩展荒原和 48 只怪物。优先继续精修野蛮人，质量目标为暗黑2重制版成品人物。

## 一、整体定位

玩家是一位从北方来到罗格营地的野蛮人。营地里的姐妹们失去了修道院，向东的商路被封锁，一个神秘旅人留下了灾祸的痕迹。玩家通过阿卡拉取得第一个委托，进入鲜血荒地寻找邪恶洞窟，并逐步卷入追寻黑暗流浪者的旅程。

体验核心：有重量的近战、怒气管理、技能与武器切换、可辨认的敌人预警、短暂安全的营地和危险的荒野。第一阶段优先建立这些体验发生的可信空间。

## 二、开场场景

营地不做只有地面和几个占位人的空地图。用 Blender 建立有功能分区的避难所：中心篝火、阿卡拉的药剂帐篷、卡夏的守卫营帐、恰西的铁匠炉、瓦瑞夫的马车、基德的摊位、传送平台、罗格木栅和北门。树林、岩石和草丛围住营地；木门外接鲜血荒地和邪恶洞窟入口。

| 人物 | 开场作用 | 第一阶段交互 |
|---|---|---|
| 野蛮人 | 玩家唯一英雄，双持/背负重武器 | 点击寻路、八段骨骼动画、六技能、受伤、死亡 |
| 阿卡拉 | 目盲之眼女祭司 | 对话、接受邪恶洞窟委托 |
| 卡夏 | 罗格卫队指挥官 | 介绍姐妹们的处境与营地外威胁 |
| 恰西 | 营地铁匠 | 打铁动作与工具遗失的剧情伏笔 |
| 瓦瑞夫 | 商队领队 | 交代东行道路与神秘旅人的背景 |
| 基德 | 商人 | 营地对话，后续扩展交易 |
| 罗格斥候 | 显示营地仍在抵抗 | 在门外与敌人交战 |
| 沉沦魔 | 第一类可战斗敌人 | 搜索目标、接近、攻击、受击、死亡 |

剧情依据：[暴雪《暗黑2》第一幕任务说明](https://classic.battle.net/diablo2exp/quests/act1.shtml)。邪恶洞窟由阿卡拉引出；卡夏的埋骨之地任务、营救凯恩、遗忘之塔、恰西的锻造工具和安达利尔按主线顺序扩展。凯恩不会在尚未营救时出现在开场营地。

**本次第一场景范围：营地可以探索、NPC 可以交谈、接受任务、走出营地参与战斗并发现洞窟入口。洞窟内部与完整任务完成链在下一阶段建设；发现入口不等于完成“清空洞窟”。**

## 三、美术质量与 Blender 工作流

视觉方向是细节丰富的风格化暗黑写实：冷灰绿色荒野、磨损木材、暗红与灰麻色帐篷、温暖炉火、可辨认的皮革与金属。优先做到统一的材质、可信的人物比例、层次清晰的光照与场景叙事，逐步补充贴图与更精细动画。

制作流程：Blender 脚本创建可编辑模型 → 保存每个角色及营地的 `.blend` → 导出 GLB → Godot 场景集成 → 最终镜头截图检查。地形小径使用生成后保存的真实纹理；大场景按材质合并以控制绘制调用；野蛮人使用连续人体与 163 根骨骼、蒙皮权重和八段导出动作；其他人物仍保留轻量关节部件。

角色优先保留野蛮人的粗壮胸肩、护肩、臂甲、皮靴、战斧、背负武器、胡须和发辫；NPC 通过服装、道具、姿势区分。野蛮人已经接入 Blender 骨骼与 AnimationPlayer 混合；人体与皮肤基础来自 MakeHuman CC0，装备、毛发、战纹、伤疤和动作在项目制作。当前仍未达到暗黑2重制版的完整成品人物质量，后续精修脸部、发丝、布料与动作。

美术验收：在实际俯视距离下仍能识别角色和武器；没有缺失贴图、离地、倒置法线或错位四肢；建筑不会遮住主路线；火光提供局部视觉中心；战斗预警能从地面中分辨。

## 四、镜头、移动与交互

使用真实 3D 世界，主要移动在 XZ 平面。相机固定旋转、缓动跟随，滚轮缩放。正交相机作为当前选择，后续可微调透视与距离，但不加入自由旋转要求。

左键点击地面设置路径；点击 NPC 先走近再交谈；点击敌人先接近再攻击。寻路避开帐篷、桌子、马车、木栅与树干。敌人、静态障碍和地面分开碰撞。点击 UI 不应同时让人物移动；暂停和对话期间禁止新的移动指令。WASD 不参与移动映射。

六技能开局全部装备且没有冷却，初始怒气 100。左键突刺、按住右键旋风斩、1 集结呐喊、2 战吼、3 腾空斩、4 狂战士之怒。Q 药剂独立于技能槽；空格闪避尚未实现。C 可切换人物近景。

## 五、当前正式版技能基线

在 2026-09-10 本次查阅中，官方补丁页列出的最新正式补丁为 **3.1.3（2026-08-12）**，社区技能数据库也标注 Season 14 / 3.1.3。检索到的 3.2.0 页面明确为 PTR；不把 PTR 值混入正式版。依据：[官方补丁页](https://news.blizzard.com/en-us/article/24287406/diablo-iv-patch-notes)、[3.2.0 PTR 说明](https://news.blizzard.com/en-us/article/24292852/the-3-2-0-ptr-what-you-need-to-know)。

3.0 已重做技能树，旧版的 Enhanced/Tactical/Power 节点不能直接照搬到当前版。当前树按三层分支记录，一层中互斥选择；完整变体按实际开放情况核对。依据：[暴雪技能树改版说明](https://news.blizzard.com/en-us/article/24267729/prepare-for-the-reckoning-lord-of-hatred-draws-near)。

| 技能 | 3.1.3 基础值 | 当前实现 |
|---|---|---|
| 突刺 | 12 怒气，90% 武器系数 | 已完成短距冲刺、近战命中、产怒 |
| 旋风斩 | 15 怒气/秒，72% 武器系数 | 已完成持续耗怒、移动与范围命中；0.5 秒命中间隔为项目调校，避免反复点按免费伤害 |
| 集结呐喊 | 消耗 35 怒气，移速 +20%，4 秒，盟友一半 | 已完成玩家和罗格斥候增益 |
| 战吼 | 增伤 7.5%，4 秒，25 秒冷却，盟友一半 | 已完成；6 秒是 Duration Increase 分支，不是本次基础值 |
| 腾空斩 | 产生 15 怒气，55% 系数，减速 70% / 3 秒，17 秒冷却 | 已完成抛物线位移、落点验证、范围伤害、减速 |
| 狂战士之怒 | 狂暴与不可阻挡 10 秒，击退附近敌人，90 秒冷却 | 已完成爆发增益、击退、免除精英减速 |

数字来源：[突刺](https://d4guides.gg/en/database/skills/lunging-strike)、[旋风斩](https://d4guides.gg/en/database/skills/whirlwind)、[集结呐喊](https://d4guides.gg/en/database/skills/rallying-cry)、[战吼](https://d4guides.gg/en/database/skills/war-cry)。这些是社区数据库的当前版参考；不能替代实机所有隐藏时序的验证。原始命中面积、动画窗口、等级缩放等未核实项保持明确记录。

还原优先级：基础行为 → 资源与冷却 → 状态/武器约束 → 所选分支 → 伤害公式与等级缩放 → 配装联动。通过怪物强度和场景节奏调整可玩性，避免暗改技能原始规则。

后续再按当前版逐项扩展升级分支、先祖之锤、双重横扫、冲锋、钢铁之握等。流血、召唤和配装联动在所需系统齐备后完成。始终只有六个装备槽，不把所有技能堆在同时激活的快捷键上。

## 六、工程结构

```text
ash-oath/
  README.md
  art/                    Blender 原始模型，人物与场景分别保存
  game/
    project.godot
    scenes/encampment.tscn
    scripts/              场景流程、人物行为、界面
    data/                 世界碰撞、技能参考、剧情数据
    assets/               GLB、纹理、音效
  tools/                  Blender 生成、音效生成、一键启动
  docs/                   制作记录、限制与验证
  artifacts/              游戏实机截图与验证输出
```

Godot 4.6.2 + GDScript。暂时由简单场景流程协调，随着技能和关卡增长拆分 CombatResolver、SkillRuntime、QuestState 与动画表现层。不要先构造大量抽象框架，再等待游戏能运行。

技术依据：[Godot 3D 模型导入](https://docs.godotengine.org/en/4.6/tutorials/assets_pipeline/importing_3d_scenes/available_formats.html)、[Camera3D](https://docs.godotengine.org/en/4.6/classes/class_camera3d.html)、[AStarGrid2D](https://docs.godotengine.org/en/4.6/classes/class_astargrid2d.html)。

## 七、开发节奏

1. **已实现：开场可运行。** 完成 Blender 场景与人物、鼠标移动、NPC 对话、任务引子与营地外战斗。用真正游戏截图检查模型与画面。
2. **已实现：野蛮人六技能与扩展荒地。** 六技能开局可用；荒原约 76 × 106 米，48 只怪物、八个怪群、三名强化头目。模型成品质量仍需继续精修。
3. **接续：邪恶洞窟。** 制作可进入的地下场景，敌人分布与头目、清空统计、返回阿卡拉交任务。
4. **接续：成长循环。** 拾取装备、属性对比、掉落、技能解锁和存档。

今晚达到的完成度按上述顺序累计，先保证每个阶段真的能玩。美术素材和工程结构继续复用到正式游戏；不为赶时间引入一次性项目命名或与长期方向冲突的玩法。

## 八、可玩验收与后续风险

- 双击启动器可进入真实 3D 营地，主角在几秒内可控制。
- 鼠标路径避开静态障碍，可从营地走到北门外；没有 WASD 移动。
- 五位 NPC 可交谈；阿卡拉委托可接受并更新任务追踪；没有假装已完成洞窟任务。
- 野蛮人能够攻击并杀死敌人，敌人能反击，罗格卫兵能交战。
- 人物有待机、跑步、挥武器、受击和倒地反馈；动画与攻击判定相连。
- 暂停冻结场景逻辑；死亡可返回营地，UI 点击不穿透。
- 检查最终截图、运行日志与一次实际交互流程，修复模型错位和脚本错误。
- 当前本机启动依赖已安装的 Godot；独立发行包需要导出模板和相应平台验证。
- 当前完成开场与六项基础技能，不宣称已完成暗黑4全技能树、完整暗黑2剧情或装备系统。旋风结算间隔、角色属性和技能半径属于项目调校。
