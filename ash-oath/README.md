# 灰烬誓约 · ASHEN OATH

Godot 桌面 ARPG：真实 3D、固定斜俯视镜头、鼠标移动，唯一英雄为野蛮人。第一幕从罗格营地开始。

## 运行

本机双击 **`tools/run.command`**。也可以用 Godot 4.6.2 打开 `game/project.godot` 按 F5。启动器依赖已安装的 Godot，可用 `ASHEN_OATH_GODOT` 指定引擎路径。

```sh
/Applications/Godot.app/Contents/MacOS/Godot --path game
```

## 开局六技能

全部已装备、冷却为零，初始怒气 100。没有等级或任务解锁门槛。

| 输入 | 动作 | 基础效果 |
|---|---|---|
| 左键地面 / 人物 | 移动 / 走近交谈 | 点击寻路，不支持 WASD |
| 左键敌人 | 突刺 | 短距逼近，90% 武器伤害，产生 12 怒气 |
| 按住右键 | 旋风斩 | 朝鼠标指向移动并范围攻击，15 怒气/秒；松手停止 |
| 1 | 集结呐喊 | 消耗 35 怒气，移动速度 +20%，4 秒；影响附近友军 |
| 2 | 战吼 | 伤害 +7.5%，4 秒；影响附近友军；25 秒冷却 |
| 3 | 腾空斩 | 跃向鼠标地面，55% 范围伤害，减速 70% 持续 3 秒，产生 15 怒气；17 秒冷却 |
| 4 | 狂战士之怒 | 击退附近敌人，狂暴与不可阻挡持续 10 秒；90 秒冷却 |

| 滚轮 / Esc | 缩放 / 暂停或关闭对话 | |
| M / F11 | 静音 / 全屏 | |
| R（死亡后） | 返回营地 | 重新开始当前场景 |

## 场景和人物

- 营地：篝火、帐篷、药剂摊、铁匠炉、马车、木门、传送平台。
- 五位可交谈人物：阿卡拉、卡夏、恰西、瓦瑞夫、基德；两名罗格斥候在门外战斗。
- 可探索边界从 56 × 66 米扩展到约 **76 × 106 米**，面积约 2.18 倍；加入废弃农舍、墓地、石板路和远处洞窟入口。
- **48 只沉沦魔，分为八群，包含三名强化头目**。头目有更高生命、伤害和减速攻击。敌人会追击、攻击、死亡，并有攻击预警。
- 阿卡拉委托可接受；向北探索可以发现邪恶洞窟。洞窟内部、交任务、交易、装备掉落与存档尚未实现。

野蛮人按《暗黑2：重制版》的光头战纹、厚实躯干和皮革装备方向重新制作：交叉肩带、贴体铆钉护肩、宽腰带、暗红分片战裙、护腕、封闭皮靴、战斧和单手剑。保留连续人体和 2K 皮肤；179 根骨骼包含 16 根独立裙片骨骼。武器握点由手指闭合位置计算，背带与护肩从最终人体表面转移蒙皮权重。

十段动作覆盖待机、奔跑、突刺、旋风、集结呐喊、战吼、狂暴、腾空、受击和死亡，按 60 Hz 烘焙；跑动使用脚部 IK 和随速度变化的播放速率。跳跃分为蓄力、腾空、落地和恢复，命中时序来自模型导出的数据。**这是参照重制版重新建模的版本，不能当作原版资产或 1:1 成品复刻；面部雕刻、材质细节和动作表现仍有差距。**

## 数值范围

六项基础技能参考《暗黑4》3.1.3 正式版工具提示；尚未实现升级分支、装备词缀、巅峰、等级缩放及原版完整伤害公式。武器伤害 32、生命 280、施法半径、动画窗口、跳跃距离和旋风斩 **0.5 秒一次命中**是本项目调校，不能声称与原版隐藏时序完全一致。原始来源与未核实项保存在 `game/data/skill_reference.json`。

## 制作与验证

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --python-exit-code 1 --python tools/build_world.py
/Applications/Blender.app/Contents/MacOS/Blender --background --python-exit-code 1 --python tools/build_barbarian.py
python3 tools/make_audio.py
python3 tools/verify.py
python3 tools/verify_barbarian.py --captures
```

场景生成脚本不会覆盖新版野蛮人。检查脚本导入资源，执行真实场景交互和六技能测试，再分别启动图形窗口截取营地、对话、荒地、人物、战斗画面。

- `art/barbarian.blend`：带骨骼、动作、材质和展示灯光的野蛮人源文件。
- `art/rogue_encampment.blend`：扩展地图源文件。
- `game/assets/models/`：实际运行的 GLB。
- `artifacts/`：运行截图、日志与验证结果。
- `artifacts/barbarian-motion/`：十段动作在真实引擎中的三视角截图。
- `artifacts/barbarian-actions.mp4`：30 秒、十段动作的三视角引擎录像。
- `game/scenes/hero_review.tscn`：可暂停、慢放的动作检查场景；也可以在游戏中按 F7 打开。
