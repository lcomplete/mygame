# 野蛮人模型工作流

更新：2026-09-11。

`tools/build_barbarian.py` 是独立 Blender 构建入口；`tools/build_world.py` 只构建环境与其他人物，不会再覆盖野蛮人。

1. 读取 CC0 基础人体 OBJ，只使用 `body` 面组；保留 UV，忽略代理衣物和关节定位辅助面。
2. 叠加男性、肌肉、体重目标并调整身高与肩宽。使用连续平滑形变增加胸腹体积。
3. 从定位点重建 163 根骨骼，映射原始蒙皮权重；一次细分用于面部、手指和身体轮廓。
4. 裤装与靴筒贴合人体；胸带转移人体权重；肩甲、护腕与武器绑定对应骨骼。所有发丝、毛皮和装备最终按材质合并，保留少量绘制表面。
5. 生成人体纹理、皮革与金属材质，保存八段骨骼动作。动作名保持 Idle、Run、Attack、Whirlwind、Shout、Berserk、Leap、Death。
6. 导出标准 GLB；修复 Blender 导出器未保留的皮肤颜色乘数。Godot 在模型外层统一朝向，使用 AnimationPlayer 混合动作，游戏逻辑控制位移和命中。
7. 保存可编辑 `.blend`，渲染近景，再从真实 Godot 场景检查导入、动画与材质。

## 质量状态

连续人体比例、手指、面部拓扑、骨骼、蒙皮和材质基础已建立；仍有明显的程序化模型特征。当前没有完成可与《暗黑2：重制版》并列的手工高模雕刻、烘焙微细节、头发卡片、服装褶皱、动作捕捉和精修。

下一轮美术工作应直接在现有源文件上雕刻或替换对应子网格，保留骨骼与动作接口；不要退回独立球体组成的肌肉占位模型。验收应包含正面、背面、近景，以及跑动、旋风和腾空过程中肩肘、腕、膝的形变。
